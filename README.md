# StudyTracker

Настольное приложение для учёта успеваемости студентов. Лабораторная работа № 1 по дисциплине
«Автоматизация процессов жизненного цикла программных средств», вариант «Приложение по учёту
успеваемости студентов».

Стек: Python, Tkinter, SQLite.

## Возможности

- вход по логину и паролю, две роли: сотрудник деканата и преподаватель;
- учёт студентов (поиск по фамилии и группе);
- учебный план: специальность, дисциплина, семестр, часы, форма отчётности;
- журнал успеваемости: добавление и изменение оценок;
- подсчёт студентов по форме обучения и данные по выбранной дисциплине;
- журнал событий (входы, ошибки, изменения оценок);
- резервные копии базы данных.

## Запуск

Нужен Python 3.12 или новее. Tkinter входит в Python, в Ubuntu при необходимости:
`sudo apt install python3-tk`.

```
python main.py
```

При первом запуске создаётся база `data/studytracker.db` с тестовыми данными
(30 студентов, 10 дисциплин, 105 оценок). Создать её вручную можно командой
`python -m studytracker.seed`.

Для тестов:

```
pip install -r requirements.txt
pytest
```

## Обработка ошибок

Для каждой ошибки пользователя есть свой класс исключения (`studytracker/errors.py`). Общий обработчик
(`studytracker/hooks.py`) отменяет операцию, показывает сообщение и записывает событие в `event_log`.

| Код | Ситуация |
| --- | --- |
| ST001 | недопустимая оценка (экзамен: 2–5, зачёт: «зачёт» или «незачёт») |
| ST002 | оценка по этой дисциплине и семестру у студента уже есть |
| ST003 | студент или дисциплина не найдены |
| ST004 | пустое поле или значение вне диапазона (год поступления 2000–2026) |
| ST005 | дисциплины нет в учебном плане специальности студента |
| ST006 | действие недоступно для роли |
| ST007 | неверный логин или пароль, после 5 ошибок вход блокируется на 5 минут |
| ST008 | файл базы данных не найден, занят или повреждён |

## База данных

Таблицы: `students`, `groups`, `specialties`, `disciplines`, `curriculum`, `grades`, `users`, `event_log`
и служебная `login_attempts` (счётчик неудачных входов). Схема описана в `studytracker/db.py`.
Пароли хранятся в виде хеша PBKDF2-SHA256 с солью.

## Резервные копии

При запуске база копируется в папку `backup/` не чаще одного раза в сутки, хранятся последние 5 копий.
Если базу не удаётся открыть, программа предлагает повторить попытку или восстановить её из последней копии.
Вручную восстановить можно так: закрыть программу и заменить `data/studytracker.db` нужной копией.

## Как пользоваться

1. Введите логин и пароль и нажмите «Войти».
2. «Студенты» — поиск по фамилии и группе, кнопки «Добавить» и «Изменить» (деканат).
3. «Учебный план» — кнопки «Добавить» и «Изменить» (деканат). Новую дисциплину можно ввести в поле «Дисциплина».
4. «Журнал успеваемости» — выберите студента, дисциплину, семестр и введите оценку. Чтобы исправить оценку,
   выберите строку и нажмите «Изменить» (преподаватель).
5. «Сводка» — выберите форму обучения или дисциплину.

Если поле заполнено неверно, оно подсвечивается красным, а в сообщении написано, что исправить.

